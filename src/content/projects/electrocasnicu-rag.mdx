## Problem

Generic chatbots hallucinate troubleshooting steps and warranty coverage when answering questions about specific home appliances. For safety- and warranty-sensitive manuals, an ungrounded answer is worse than an explicit refusal.

## Architecture & Key Decisions

* **Decoupled indexing and query runtime:** Document chunking, page-number extraction, and local embedding indexing run independently from the Streamlit execution layer, keeping chat responses fast and reproducible.
* **Strict Pydantic validation:** Tool inputs and response structures are validated through typed Pydantic schemas that verify every cited document name and page reference against the retrieved ChromaDB context.
* **Explicit refusal guardrail:** When retrieval confidence drops below threshold or evidence is absent, the agent refuses cleanly rather than speculating.
* **Automated test suite:** Core retrieval contracts, tool schemas, and citation assertions are backed by automated Python tests.
