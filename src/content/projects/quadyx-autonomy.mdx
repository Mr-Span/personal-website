## Context (Technical Side Venture)

Built as a co-founded engineering exploration alongside my primary Applied AI & Automation career, **QUADYX** focuses on reliable onboard spatial awareness and communication resilience for autonomous drones.

## System Highlights

* **Real-time spatial perception:** Combines **ORB-SLAM3** visual-inertial tracking with **Depth Anything V2** monocular depth estimation.
* **Hybrid C++/Python runtime:** Latency-critical tracking and point-cloud obstacle clustering run in C++ / OpenCV while modular orchestration, monitoring, and model evaluation run in Python.
* **Multi-channel telemetry fallback:** Integrates **ROS 2** with GSM and IP telemetry links overseen by a Python signal-monitoring watchdog that executes automatic failover on link degradation.
